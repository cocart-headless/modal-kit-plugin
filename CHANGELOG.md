# Changelog

All notable changes to Modal Kit. Versions follow [Semantic Versioning](https://semver.org/).

## 1.0.1 - 2026-11-27

### Fixed

- The Soft style keeps its rounded corners on themes that set button corners to 0.
- The Soft style keeps the room for the close button and each layout's own spacing.
- In the Editorial style, headings, outline buttons and focus rings stay visible on themes that set their own colours for them.

## 1.0.0 - 2026-11-27

- First release: modals made of blocks. Popups, slide-ins, bars, drawers, full-screen takeovers, bottom sheets, inline panels and a video lightbox, built with the core blocks you already use.
